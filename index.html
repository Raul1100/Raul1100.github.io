11.9%WAPE (−18% vs seasonal naive)

Problem

Purchase and production planning need demand forecasts weeks ahead, and the right method isn't obvious until you test them all on the same data.

What I built

A browser app that simulates 3 years of weekly demand for 10 SKUs (trend, seasonality, a festive-season bump, promotions) and compares six hand-written models: naive, seasonal naive, moving average, Holt-Winters, ridge regression on lag and calendar features, and an ensemble. It runs a 4-fold rolling-origin backtest over an 8-week horizon and includes an automated leakage test.

Result

On the sample data the Holt-Winters + ridge ensemble reaches 11.9% WAPE, 18% less error than seasonal naive, and every model passes the leakage test.

Built with JavaScript, Holt-Winters, Ridge regression, Time series, Chart.js

77%of churners reached in the top 20%

Problem

A sales team can only call so many customers a week, so it needs to know which active accounts are about to go quiet.

What I built

Simulates 520 B2B customers with their own ordering rhythms, takes monthly snapshots with seven behavioural features, and trains a logistic regression in the browser on a time-based split. It compares the model with a 60-day inactivity rule, recency ranking and RFM segments, and explains each risk score.

Result

On the test snapshot, calling the riskiest 20% reaches 77% of churners and 62% of revenue at risk (AUC 0.95), against 61% when ranking by days since last order.

Built with JavaScript, Logistic regression, RFM, Chart.js

How I work

The same five steps for a WhatsApp agent or a stock dashboard.

  1. Sit with the users

    Shadow the people doing the work, map the current process and define the decisions the tool has to support.

  2. Wire up the data

    Connect sheets, databases and APIs. Clean the data, validate it and give every record a single key.

  3. Model & analyse

    Add the logic: KPIs, forecasts, churn scores, matching rules, or an LLM agent with tools and RAG.

  4. Build the interface

    Ship a dashboard, a web app or a chat/WhatsApp agent, designed for the person using it at 9 AM.

  5. Automate & hand off

    Triggers, schedulers, alerts and deploy on Render or Apps Script, then document it and support it.
