How it works

each order gets planned dates by adding each stage's SLA in working days (Sundays skipped) to the previous stage's actual date, or its planned date if not done yet, so a slip ripples forward. Marking a stage done stamps today's date. Orders are saved in localStorage; "Reset sample data" restores the starting set of 36 orders from cafés, QSR chains, caterers, distributors and three export buyers.
